Publicar cambios

Tu tienda es estática (sin servidor), así que los cambios se publican reemplazando un archivo. Son tres pasos y no necesitas saber programar.

Importante: lo que editas aquí se guarda como borrador en este navegador (lo ves solo tú). Para que lo vean todos tus clientes, descarga catalog.js y súbelo a tu hosting reemplazando el anterior.

Los tres pasos

1

Descarga el catálogo actualizado

Genera el archivo catalog.js con todos tus productos y ajustes.

2

Súbelo a tu hosting

Entra al panel de tu hosting (Netlify, cPanel, GitHub Pages…) y reemplaza catalog.js por el nuevo. Si usas Netlify puedes arrastrar la carpeta completa.

3

Abre la tienda y listo

Recarga la web y verás los cambios. Si no aparecen, borra la caché del navegador o abre en una ventana privada.

Sin complicaciones

Ayuda rápida

Todo lo que necesitas para mantener la tienda al día.

Cambiar un precio

Productos → lápiz del producto → escribe el nuevo precio → Guardar producto → Publicar.

Cambiar una foto

Abre el producto, arrastra la nueva imagen sobre el recuadro (o haz clic para elegirla). Se recorta y comprime automáticamente para que se vea bien en móvil, tablet y computadora. Guarda y publica.

Marcar algo como agotado

Desactiva el interruptor «Disponible para pedir». El producto sigue visible pero no se puede añadir al carrito.

Cambiar el WhatsApp

Ajustes → WhatsApp → escribe el número con código de país, sin + ni espacios (ej.: 5354015519) → Guardar ajustes → Publicar.

¿Dónde se guardan las imágenes?

Dentro del propio catalog.js, comprimidas. Por eso al publicar no se rompe ninguna foto aunque cambies de hosting. Si tienes muchas fotos grandes, conviene subirlas a la carpeta img/ y usar la ruta (ej.: img/mi-jabon.jpg).

Abrir el panel en otro dispositivo

El acceso es tudominio.com/admin.html. La contraseña se guarda en cada navegador, así que cámbiala ahí también. No compartas el enlace del panel.

SEO: que te encuentren en Google

La web ya incluye datos estructurados de producto, negocio local y preguntas frecuentes. Cuando tengas dominio propio: cambia la dirección en Ajustes, sube sitemap.xml y robots.txt, y da de alta el sitio en Google Search Console.
